# AI Image Classification using MobileNetV2

## 📌 About Project

This project is **Task 3 of the CodeOrbit Tech Internship**.
It is an AI-based Image Classification application developed using **Python, Tkinter, TensorFlow, Keras, and MobileNetV2**.

The application allows users to upload an image and get the predicted image category with a confidence percentage.

## ✨ Features

* Choose Image
* Image Preview
* AI Image Prediction
* Confidence Percentage
* Progress Bar
* Clear Button
* Exit Button
* User-friendly GUI

## 🛠️ Technologies

* Python
* Tkinter
* TensorFlow
* Keras
* MobileNetV2
* NumPy
* Pillow

## ⚙️ Installation

Install required libraries:

```bash
pip install tensorflow pillow numpy
```

## ▶️ Run

```bash
python app.py
```

Then click **Choose Image → Select Image → Predict**.

## 🤖 Model

**MobileNetV2** with pre-trained ImageNet weights is used for image classification.
